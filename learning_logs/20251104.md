# 금일 최소 단위
1. SignUp / SignIn 과정
  - 특히 SignUp의 경우에는 username / password / 및 기타 정보만 받았지만 DB에 다른 field들이 생성되어야된다는 점 때문에 신경써야 할 부분이 있습니다.
2. 발표 자료 준비 시작
  - PPT / 미리캔버스 / 캔바 등 자유
  - 들어가는 항목(예시)
    1. 프로젝트 소개
    2. 팀 및 팀원 소개
    3. 기술 스택 / 개발 도구 / 협업 툴
    4. 앱 구조도
    5. 초기 ERD -> 추후 변경 과정을 최종 발표 때 삽입해주면 좋을 것 같습니다(특정 이유를 바탕으로).
    6. 주요 기능
      - 수업 내용
      - 수업 외 연구 내용
    7. 프로젝트 일정
    8. 해당 프로젝트 경험을 통해 얻고자 하는 경험 혹은 포부
