# 금일 최소 단위
1. ERD 기준으로 Entity를 만들어서 JPA 준비를 해야합니다.
2. JPA를 만들었다면 SpringBoot App 실행 시 DB에 테이블들이 만들어져야하는데, 이를 위한 준비도 필요하겠네요.
3. JpaRepository를 상속해서 만들었다면, Postman을 통한 테스트 역시도 가능할겁니다.
4. 또한 너무 여러 Entity들로 인해서 api를 다루기 어렵다면, OpeanAPI를 통해서 Swagger를 사용하는 것도 고려해볼만 합니다.
5. 이상의 개념에서 모르는 점이 있다면 학습이 요구됩니다.
6. FrontEnd는 아직 얘기 안했죠. 라이브러리 학습이 요구됩니다.
